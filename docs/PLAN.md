## 1. Цель одним абзацем

Веб-симулятор разговора о деньгах. Пользователь говорит, к чему готовится, отвечает на короткий квиз, выбирает собеседника и **голосом или текстом** ведёт переговоры с собеседником, который не уступает просто так. После разговора видит разбор: **деньги** (сколько оставил на столе против своего диапазона и на каком ходу) и **подача** (темп, паузы перед цифрой, смягчители). Может переиграть ту же партию.

## 4. Архитектура

```
Браузер (Next.js 16)
 ├─ квиз, сессия, разбор, план ......... React + Tailwind (токены брендбука)
 ├─ push-to-talk ....................... MediaRecorder → POST /api/voice/stt
 └─ воспроизведение реплики ............ GET /api/voice/tts (стрим mp3)

Сервер (Route Handlers)
 ├─ POST /api/demo/login ............... cookie-сессия демо-пользователя
 ├─ POST /api/session .................. QuizAnswers → ScenarioConfig (шаблон или Сценарист) → SessionState в БД
 ├─ POST /api/turn ..................... реплика → Классификатор → Ядро → Актёр → ответ + новое состояние
 ├─ POST /api/voice/stt ................ Scribe → текст + таймстемпы → метрики подачи хода
 ├─ GET  /api/voice/tts ................ ElevenLabs TTS голосом персонажа
 ├─ POST /api/debrief .................. суммы кодом, комментарии LLM
 ├─ POST /api/polar/checkout, /webhook . оплата
 └─ лимиты: N сессий на IP в день, потолок расходов в сутки, длина сессии ≤ 12 ходов

Postgres: users, scenarios, sessions, turns, subscriptions
```

### 4.1 Агенты вокруг детерминированного ядра

| Агент | Тип | Вход → выход |
|---|---|---|
| Сценарист | LLM (sonnet), 1 раз | описание пользователя → `ScenarioConfig` по схеме zod; невалидно → откат на шаблон архетипа |
| Классификатор | LLM (haiku) | реплика → `{ moveType, amount?, hasReason, hedges[] }`; невалидно → повтор → `offtopic` |
| Ядро | чистый TS | `(CoreState, Move) → (CoreState', CounterpartAction)` |
| Актёр | LLM (sonnet) | `CounterpartAction` + персона → реплика; суммы в тексте сверяются с ядром |
| Разборщик | код + LLM | суммы и метрики — код; `betterLine` и комментарии — LLM |

Типы — `src/engine/types.ts` (контракт для UI). Таблица переходов — в коде и тестах, не в этом документе.

### 4.2 Метрики подачи (слой 2)

| Метрика | Источник | Подпись в UI |
|---|---|---|
| Темп, слов/мин, % к норме | таймстемпы Scribe; норма = калибровка или первый ход | измерение |
| Пауза перед первой цифрой | таймстемпы | измерение |
| Паразиты (um, uh, like) | verbatim-транскрипт | измерение |
| Смягчители (maybe, just, sorry, I think, kind of) | текст | измерение, работает и в текстовом режиме |

**Проверить до 21:30 (Керей):** Scribe оставляет «um/uh» в verbatim? Если нет — метрика паразитов уходит, остаются смягчители.

## 8. Вопросы жюри
- **Откуда потолок?** Параметр сценария из диапазона, который ввёл пользователь. Говорим «against your range», не «your boss would have paid».
- **Почему не ИИ торгуется за меня?** Счёт делегировать можно, разговор с начальником нет.
- **Зачем вернутся?** Очередь разговоров с датами, переигровка, новые сценарии.
- **Что захардкожено?** Ни одной цифры: суммы считает ядро, тесты в репо.
- **Точность голосовых метрик?** Измерения из таймстемпов, без «оценок характера».
